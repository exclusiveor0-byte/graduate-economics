# 논문 아카이브 작성 규칙

논문 노트는 `literature/<분야>/연도-첫저자-핵심어.qmd`에 둔다. 처음에는 아래 여덟 분야 중
가장 가까운 하나를 고른다. 여러 분야와 관련되면 주 분야에 파일을 두고 다른 분야 허브 또는
관련 노트에서 링크한다.

- `theory-micro`
- `macro-monetary`
- `econometrics-methods`
- `finance`
- `labor-health-education`
- `public-policy`
- `io-trade`
- `development-environment-urban`

새 노트는 `templates/paper-note-template.qmd`를 복사해 작성한다. 제목·서지정보·원문 링크,
질문, 설계, 핵심 결과, 기여와 한계, 저장소 안의 연결을 채운다. 논문 전체 PDF나 유료 원문을
commit하지 않으며, DOI·공개 저장소·저자 페이지 링크를 사용한다.
