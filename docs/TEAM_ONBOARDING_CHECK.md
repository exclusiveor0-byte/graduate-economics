# 팀원 첫 Pull Request 확인표

처음 참여할 때는 오탈자 하나로 아래 흐름을 연습합니다.
이 표는 실제 팀원이 수행한 뒤 체크하세요. 자동 렌더 성공은 팀원 온보딩 완료를 뜻하지 않습니다.

- [ ] GitHub Desktop에서 main을 선택하고 Fetch origin, 필요하면 Pull origin을 실행했다.
- [ ] 새 작업 branch를 만들었다.
- [ ] Section 하나의 `.qmd`를 VS Code에서 수정했다.
- [ ] 로컬 미리보기에서 바뀐 부분을 확인했다.
- [ ] Commit → Push → Create Pull Request를 완료했다.
- [ ] Files changed에서 의도한 파일과 문장만 바뀌었는지 확인했다.
- [ ] Quarto Render Check의 초록 체크를 확인했다.
- [ ] 리뷰어에게 확인할 부분을 PR 본문에 적었다.
- [ ] 검토와 merge 후 Pages에서 반영된 내용을 확인했다.
- [ ] Desktop에서 main → Fetch/Pull로 돌아왔다.

작은 문장 수정은 GitHub 웹의 연필 버튼에서 새 branch와 PR을 만드는 방법으로도 연습할 수 있습니다.
수식·증명 검토는 렌더 검사와 별도로 진행합니다. 충돌이 생기면 PR 링크를 maintainer에게 전달하세요.
