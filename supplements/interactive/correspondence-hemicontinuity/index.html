대응의 반연속성과 닫힌 그래프: UHC와 LHC의 위상수학적 판정

개집합 포섭 조건(F(x) ⊆ V)과 수열적 접근성(yk → y₀)을 파이버(Fiber) 기하학으로 탐색합니다.

조작 가이드 (Operational Workflow):
  1. 프리셋 선택: 상단 5개 대표 대응(A~E) 중 하나를 선택하여 위상적 구조를 설정합니다.
  2. 검증 모드 전환: UHC (개집합 포섭)와 LHC (수열 접근) 탭을 번갈아 선택합니다.
  3. 모수 탐색 프로브 x 조작: 슬라이더를 좌우로 천천히 움직여 기준 특이점 x₀(=0) 근방에서 파이버 F(x)의 팽창(외측 폭발) 또는 수축(내측 증발)을 관찰합니다.
  4. 위상 판정 확인: UHC 모드에서는 F(x)가 개근방 V 상자 안에 머무는지(녹색) 바깥으로 탈출하는지(적색)를, LHC 모드에서는 x → x₀일 때 선택지 거리 d(y₀, F(x))가 0으로 수렴하는지 확인합니다.
모수 탐색 프로브 x (Parameter Probe) 0.00
외생변수 x를 연속적으로 스크러빙(scrubbing)하여 기준점 x₀ 근방 U 내부와 외부에서 파이버 F(x)의 거동을 직접 검증합니다.
개근방 V의 여유 반경 ε (Radius) 0.20
기준 파이버 F(x₀)를 둘러싸는 열린 개집합 V = (inf F(x₀) − ε, sup F(x₀) + ε)를 설정합니다. UHC가 성립하면 직적 근방 상자 U × V가 화면에 형성됩니다.
기준 선택원소 y₀ ∈ F(x₀) 0.80
기준 특이점 x₀에서 선택 가능한 실현값 y₀를 지정합니다. x → x₀일 때 F(x) 내에서 y₀로 다가가는 최단 투영점 y*(x)의 연속 경로를 추적합니다.
기준 특이점: x₀ = 0.00, F(x₀) = [0.00, 1.00]
